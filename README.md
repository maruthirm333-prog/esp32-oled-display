# ESP32 OLED Display

SSD1306 OLED display (128×64) with ESP32 over I2C.

## Wiring
| OLED | ESP32 |
|------|-------|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |

## Library
Install **Adafruit SSD1306** + **Adafruit GFX** via Arduino Library Manager.
